# Slagg

**Falk Instruments** – analog-inspirerad trummaskin för mörk techno. VST3 (Mac + Windows) och AU (Mac).

- 10 analoga ljud: Kick, Snare, Clap, Rim, Closed hat, Open hat, Cymbal, Tom low/mid/high
- Per ljud: Tune, Decay, Tone/Sweep, Snap/Click/Noise, Drive, Cutoff, Reso, Level, Pan, egen utgång
- Sekvenserare: 32 steg, velocity per steg, egen längd per ljud (polymeter), swing
- **Dra MIDI till DAW** per ljud eller alla (ett spår per ljud), längd från DAW:ns markörer
- 11 utgångar: Main + en per ljud
- MIDI in med GM-trumnoter

Se `packaging/*/INSTALLERA.txt` för installation och snabbstart. Bygg/test: se `CLAUDE.md`.
